3. AUTENTICAÇÃO DROPBOX - HISTÓRICO E SOLUÇÃO
========================================================================

Problema Inicial:
  - App original criado com tipo "Acesso limitado", chave: autexfxe12rb2033
  - SDK "dropbox" (npm) dava erro "this.fetch is not a function" no Next.js
  - Token de curta duração (4h) expirava constantemente

Solução Implementada:
  1. Trocou SDK por API HTTP nativa do Dropbox (fetch do Node 18+)
  2. Criou novo app Dropbox "ClubeDoCinema2" (chave: ym36yayzcaneiqk)
  3. Configurou permissões corretas (files.content.read/write, metadata.read)
  4. Gerou refresh_token permanente via OAuth2 (não expira)

Estado Atual:
  ✅ Comunicação com Dropbox estável
  ✅ Refresh token válido e funcionando
  ✅ Sem necessidade de renovação manual
  ✅ Token renova automaticamente quando expira (via dropboxClient.js)

11. CHECKLIST DE TROUBLESHOOTING
========================================================================

Se o app não carregar a lista de pessoas:

  ☐ Verificar variáveis de ambiente na Vercel (Settings → Environment Variables)
  ☐ Testar localmente: npm run dev → http://localhost:3000
  ☐ Se local funciona, problema é na Vercel:
    - Redeploy: Deployments → ⋯ → Redeploy
  ☐ Se local não funciona:
    - Verificar .env.local (todos os 5 valores presentes?)
    - Verificar arquivo no Dropbox (existe? permissões?)
    - Testar API direto: curl http://localhost:3000/api/people
  ☐ Logs: Vercel Dashboard → Deployments → Build Logs

Se o refresh_token expirar:

  ☐ Rodar: dropbox-auth.bat (no terminal, Windows)
  ☐ Autorizar no Dropbox (clique "Permitir")
  ☐ Copiar código gerado
  ☐ Cola no script e roda
  ☐ Copiar refresh_token da resposta JSON
  ☐ Atualizar na Vercel: Settings → Environment Variables → DROPBOX_REFRESH_TOKEN
  ☐ Redeploy: Deployments → Redeploy
